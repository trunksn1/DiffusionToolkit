# CivitAI Collections Scraper - Refactoring Plan

## Overview
Move hardcoded configuration values to a user preferences file to make the script more flexible and user-friendly. The preferences file will store user-specific settings like collection selections, download paths, and page limits.

### 2.2 `api_client.py`

**Method 1: Get Current User ID**
```python
def get_current_user(self) -> Optional[Dict[str, Any]]:
    """
    Get current authenticated user information.
    Returns user data including user_id needed for fetching collections.
    """
    try:
        response = self.session.get(f"{self.api_base}/v1/users/me", timeout=10)
        if response.status_code == 200:
            return response.json()
        return None
    except Exception as e:
        logger.error(f"Failed to get current user: {e}")
        return None
```

**Method 2: Fetch All User Collections**
```python
def get_all_collections(self, user_id: int) -> List[Dict[str, Any]]:
    """
    Fetch all collections for the authenticated user.
    Uses tRPC endpoint: collection.getAll

    Returns list of collections with id, name, and image_count.
    """
    try:
        # Build tRPC query
        input_data = {
            "userId": user_id,
            # May need additional parameters - verify with browser DevTools
        }

        trpc_input = {
            "json": input_data
        }

        params = {
            "input": json.dumps(trpc_input, separators=(',', ':'))
        }

        url = f"{self.trpc_url}/collection.getAll"

        response = self.session.get(url, params=params, timeout=30)
        response.raise_for_status()

        data = response.json()

        # Parse tRPC response
        collections_data = data.get('result', {}).get('data', {}).get('json', [])

        return collections_data

    except Exception as e:
        logger.error(f"Failed to fetch user collections: {e}")
        return []
```

**Lines**: After line 321 (after `get_collection_info` method)

**Note**: The exact tRPC endpoint structure may need verification by inspecting browser network traffic on CivitAI. Use Chrome DevTools → Network tab → Filter by "collection" while viewing your collections page.

```python
def load_preferences(config: dict) -> Optional[dict]:
    """
    Load user preferences from user_preferences.yaml.
    Returns None if file doesn't exist (first run).
    """
    prefs_file = Path('user_preferences.yaml')

    if not prefs_file.exists():
        return None

    try:
        with open(prefs_file, 'r', encoding='utf-8') as f:
            prefs = yaml.safe_load(f)

        logger.info("Loaded user preferences")
        return prefs

    except Exception as e:
        logger.error(f"Failed to load preferences: {e}")
        return None
```

**2. Add New Function: Generate Preferences File**
```python
def generate_preferences_file(orchestrator: DownloadOrchestrator, config: dict):
    """
    Generate user_preferences.yaml on first run.
    Fetches all collections from CivitAI and creates template.
    """
    print("\n" + "="*60)
    print("First Run Setup - Generating user_preferences.yaml")
    print("="*60)

    # Get current user
    user_data = orchestrator.api_client.get_current_user()
    if not user_data:
        print("ERROR: Could not get user information from CivitAI")
        print("Make sure you're logged into CivitAI (use 'test-auth' command)")
        sys.exit(1)

    user_id = user_data.get('id')
    username = user_data.get('username', 'Unknown')

    print(f"Authenticated as: {username} (ID: {user_id})")
    print("Fetching your collections from CivitAI...")

    # Fetch all collections
    collections_data = orchestrator.api_client.get_all_collections(user_id)

    if not collections_data:
        print("WARNING: No collections found for your account")
        collections_list = []
    else:
        collections_list = [
            {
                'id': coll.get('id'),
                'name': coll.get('name'),
                'enabled': False,  # Disabled by default
                'image_count': coll.get('imageCount', 0)
            }
            for coll in collections_data
        ]
        print(f"Found {len(collections_list)} collections")

    # Build preferences structure
    from datetime import datetime
    preferences = {
        'base_download_path': config['paths']['downloads'],  # Copy from config
        'max_pages_per_collection': 3,  # New default
        'collections': collections_list,
        'metadata': {
            'last_updated': datetime.now().strftime('%Y-%m-%d %H:%M:%S'),
            'civitai_user_id': user_id,
            'last_fetch_date': datetime.now().strftime('%Y-%m-%d')
        }
    }

    # Write to file
    prefs_file = Path('user_preferences.yaml')
    with open(prefs_file, 'w', encoding='utf-8') as f:
        yaml.dump(preferences, f, allow_unicode=True, sort_keys=False)

    print(f"\n✓ Created user_preferences.yaml with {len(collections_list)} collections")
    print("\nIMPORTANT: All collections are disabled by default.")
    print("Edit user_preferences.yaml and set 'enabled: true' for collections you want to download.")
    print("\nYou can also edit:")
    print("  - base_download_path: Where to save images")
    print("  - max_pages_per_collection: How many pages to fetch (3 = ~300 newest images)")
    print("\n" + "="*60)
```

## 11. Critical Analysis & Review (Added 2026-01-09)

### 11.1 Robustness Concerns

#### **CRITICAL ISSUE 1: API Dependency Risk**
**Problem**: The plan relies on an undocumented tRPC endpoint (`collection.getAll`) for first-time setup.

**Risks**:
- CivitAI API structure is not publicly documented and could change without notice
- If the endpoint doesn't exist or has different structure, setup will fail
- Network issues or API downtime will block new users from using the script
- No fallback if API call fails

**Recommended Fix**:
- **Phase 1**: Don't require API call on first run
- Instead: Copy collections from existing `config.yaml` to `user_preferences.yaml`
- **Phase 2**: Add a separate command `python main.py refresh-collections` that calls the API
- This makes the API call optional and non-blocking

#### **CRITICAL ISSUE 2: Orchestrator Initialization Timing**
**Problem**: Current plan creates `DownloadOrchestrator` BEFORE loading preferences.

**Why This Breaks**:
```python
# Current plan (WRONG):
orchestrator = DownloadOrchestrator(config)  # Uses old config paths
preferences = load_preferences(config)       # Load preferences
config['paths']['downloads'] = preferences['base_download_path']  # Too late!
```

The orchestrator's `Storage` class is initialized in `__init__` with paths from config. Changing config AFTER initialization has no effect because:
- `storage.py` already created directory structure
- Database paths already set
- Check paths already cached

**Recommended Fix**:
```python
# CORRECT order:
config = load_config(args.config)
preferences = load_preferences(config)

# Merge preferences into config BEFORE creating orchestrator
if preferences:
    config['paths']['downloads'] = preferences.get('base_download_path', config['paths']['downloads'])
    config['api']['max_pages_per_collection'] = preferences.get('max_pages_per_collection', 3)
    config['collections'] = [c for c in preferences.get('collections', []) if c.get('enabled')]

# Now create orchestrator with merged config
orchestrator = DownloadOrchestrator(config)
```

#### **ISSUE 3: Insufficient Error Handling**
**Problem**: No validation or error recovery for:
- Malformed `user_preferences.yaml` (invalid YAML syntax)
- Missing required fields (e.g., `collections` key missing)
- Invalid paths (non-existent directories, permission issues)
- Empty or null values

**Recommended Fix**: Add validation function:
```python
def validate_preferences(prefs: dict) -> tuple[bool, str]:
    """Validate preferences structure. Returns (is_valid, error_message)."""
    if not isinstance(prefs, dict):
        return False, "Preferences file is not a valid dictionary"

    if 'base_download_path' not in prefs:
        return False, "Missing required field: base_download_path"

    if not prefs.get('collections'):
        return False, "No collections found in preferences"

    # Validate path exists and is writable
    path = Path(prefs['base_download_path'])
    if not path.exists():
        return False, f"Download path does not exist: {path}"

    return True, ""
```

#### **ISSUE 4: Command Argument Conflicts**
**Problem**: Existing command-line arguments (`--collection`, `--name`) may conflict with preferences file.

**Current behavior**:
```bash
python main.py sync --collection 123456 --name "Test"
```

**With preferences file**: Should this override preferences? Use preferences? Mix both?

**Recommended Fix**: Command-line arguments should take precedence over preferences:
```python
if args.collection:
    # CLI override - use specified collection
    collections = [{'id': args.collection, 'name': args.name or f'Collection_{args.collection}'}]
else:
    # Use preferences or config
    collections = config.get('collections', [])
```

#### **ISSUE 5: Dry-Run and Stats Commands**
**Problem**: Multiple commands (dry-run, stats) directly access `config['collections']`. They need updating too.

**Files affected**:
- `cmd_dry_run()` in main.py:178
- `cmd_stats()` in main.py:350
- Any other command that iterates collections

**Recommended Fix**: Ensure all commands use the merged config with preferences applied.

### 11.2 Potential Breaking Changes

#### **BREAKING CHANGE 1: Config Structure Modification**
**Risk**: Code that directly accesses `config['paths']['downloads']` may break if it runs before preferences are merged.

**Impact**: Medium
**Mitigation**: Ensure preferences are merged IMMEDIATELY after loading config, before any other initialization.

#### **BREAKING CHANGE 2: Storage Path Changes**
**Risk**: If user changes `base_download_path` in preferences, existing downloads won't be found.

**Impact**: High - will re-download all images!
**Mitigation**: Add warning message when path changes:
```python
if preferences and preferences.get('base_download_path') != config['paths']['downloads']:
    print("WARNING: Download path changed from config.yaml")
    print(f"  Old: {config['paths']['downloads']}")
    print(f"  New: {preferences['base_download_path']}")
    print("  Existing downloads may not be detected (possible re-downloads)")
    input("Press Enter to continue or Ctrl+C to abort...")
```

#### **BREAKING CHANGE 3: Collection ID/Name Mismatch**
**Risk**: Collection names might differ between config.yaml and CivitAI API, causing confusion.

**Example**:
- config.yaml: `name: "Josè"`
- CivitAI API: `name: "José"` (different encoding)
- User won't recognize the collection

**Mitigation**: When copying from config.yaml, preserve exact names. Add note in preferences file about API names.

```python
def generate_preferences_from_config(config: dict) -> bool:
    """
    Generate user_preferences.yaml from existing config.yaml.
    Simple migration without API calls.
    Returns True if successful.
    """
    print("\n" + "="*60)
    print("Migrating to user_preferences.yaml")
    print("="*60)

    # Get collections from config
    collections = config.get('collections', [])

    if not collections:
        print("No collections found in config.yaml")
        return False

    # Build preferences structure (minimal, no metadata)
    preferences = {
        'base_download_path': config['paths']['downloads'],
        'max_pages_per_collection': config['api'].get('max_pages_per_collection', 0) or 3,
        'collections': [
            {
                'id': coll['id'],
                'name': coll['name'],
                'enabled': True,  # Enable existing collections by default
            }
            for coll in collections
        ]
    }

    # Write to file
    prefs_file = Path('user_preferences.yaml')
    try:
        with open(prefs_file, 'w', encoding='utf-8') as f:
            yaml.dump(preferences, f, allow_unicode=True, sort_keys=False)

        print(f"\n✓ Created user_preferences.yaml with {len(collections)} collections")
        print("\nAll existing collections have been enabled.")
        print("Edit user_preferences.yaml to disable any you don't want.")
        print("\n" + "="*60)
        return True

    except Exception as e:
        print(f"\nERROR: Failed to create preferences file: {e}")
        return False
```
